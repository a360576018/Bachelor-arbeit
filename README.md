# Bachelor-arbeit

Dieses Repository enthält den Code zu meiner Bachelorarbeit.

`main.py` startet die Hauptversuche, `train_export.py` speichert die Modelle für den Hardwarevergleich, und im Ordner `docker_evaluation` befinden sich die Dateien und die Anleitung für die Auswertung auf verschiedenen Geräten.

Der MVTec-AD-Datensatz muss separat heruntergeladen werden, und die Datenpfade müssen vor dem Start angepasst werden.
